# aiml-crash-hardikjain

Day 1 self-practice — 10 Python tasks covering variables, loops, functions, dicts, and more.

## Files

| File | What it does | How to run |
|---|---|---|
| `intro.py` | Prints a 4-line self-introduction using variables and f-strings | `python intro.py` |
| `skills_counter.py` | Prints a numbered skill list with `enumerate()` and shows the total | `python skills_counter.py` |
| `even_odd.py` | Asks for a number and classifies it as even, odd, or zero; handles bad input | `python even_odd.py` |
| `tip_calculator.py` | Calculates tip and total for 3 test bills using a function that returns a dict | `python tip_calculator.py` |
| `word_frequency.py` | Counts word frequency in a sentence; shows both manual and `Counter` approaches | `python word_frequency.py` |
| `calculator.py` | Interactive calculator using dict-based function dispatch; handles ÷ 0 | `python calculator.py` |
| `grade_classifier.py` | Classifies 5 students' grades and prints them sorted highest to lowest | `python grade_classifier.py` |
| `guessing_game.py` | Random number guessing game with a 7-attempt limit | `python guessing_game.py` |
| `contact_book.py` | Case-insensitive contact search over a list of dicts | `python contact_book.py` |

## Setup

```bash
git clone https://github.com/hardik450/aiml-crash-hardikjain.git
cd aiml-crash-hardikjain
python -m venv .venv
source .venv/bin/activate   # macOS / Linux
.venv\Scripts\activate      # Windows
python --version
```

## Notes

- All scripts run on Python 3.10+.
- No third-party packages required.
- Every file has a comment at the top explaining what it does.
